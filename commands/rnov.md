# /rnov

Follow the `using-rnov-skills` skill.

## Steps

1. Classify the task: size, novelty, surface, risk (see `using-rnov-skills`).
2. Pick the standard flow for the task, or the earliest phase whose inputs exist.
3. Load only the chosen skill's SKILL.md; do not open five skills to be safe.
4. If no skill fits, say so and stop instead of forcing the nearest one.

## Output

Three-line classification plus the next skill to run.
