# /rnov-goldfish-readiness

Follow the `review` skill, Goldfish protocol (document review) section.

## Steps

1. Follow the `review` skill, Goldfish protocol, stage 5 (Implementation readiness), over the detailed range.
2. Check the file list is complete with a rationale per file, test assertions are named, and no decision is left to the implementer.
3. Where code already exists, check the document against it for missing logic, unstated assumptions, and undocumented edge cases.

## Output

Readiness verdict plus the list of decisions the document leaves open, if any.
