# /rnov-goldfish

Follow the `review` skill, Goldfish protocol (document review) section.

## Steps

1. Follow the `review` skill, Goldfish protocol section: semantic split first (Detailed Implementation header).
2. Stage 1 initial zoom-out, then stage 2 comprehension, stage 3 critic (lenses in parallel, synthesised), stage 4 intermediate zoom-out with the stage 1 report, stage 5 implementation readiness.
3. Each stage is a fresh reviewer; at most one re-audit per stage.
4. Consolidate into REVIEW.md with a traceability line per finding; per-stage reports live in the run folder.

## Output

Consolidated findings in REVIEW.md with suite severities; per-stage reports in the run folder.
