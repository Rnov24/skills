# Proving run A-007 — two-pass uniqueness check on a real brief

Run: 2026-10-24. Subject brief: a public landing page for Linkstash,
a real project with an adopted DESIGN.md. Evidence in this folder:
`preview-block.md`, containing the brief, the uncorrected pass-1
direction, and the pass-2 review table.

## What the run exercised

The three mechanisms A-007 merged into the suite: the two-pass
default-ness review in `design`'s preview block, the five default
clusters and chrome bans in `taste-core.md` / `templates/design.md`,
and the Chanel single-boldness rule in build discipline.

## Evidence

Pass 1 was written deliberately uncorrected and is preserved verbatim
in the preview block — it is genuinely the default shape (card kit,
gradient, arrow CTA, middle-dot nav, styled headline keyword). Pass 2
disposed of six elements, each cited against a named rule rather than
a taste claim, and the surviving direction spends its single boldness
on the product's own form as hero, per the Chanel rule. The
cream+terracotta near-miss was checked by values against the cluster
definition and recorded as not-a-hit in both this run and A-005's,
which is the calibration working consistently across two runs.

## Findings written back

- The check is only as honest as pass 1. A worker that quietly
  pre-corrects pass 1 makes the table theatre. The preview block
  format should keep pass 1 verbatim (as here) so a reviewer can
  see what was actually caught; this run records that as the
  expected practice rather than proposing a format change.
- No rule in taste-core needed amendment; nothing in the brief
  produced a false positive.

## Verdict

The merged mechanisms caught real defaults in a real brief before
code, with citations a reviewer can check. A-007 is ready to promote
EXPOSED → ADAPTED.
